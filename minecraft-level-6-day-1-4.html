Hari 1
Otomatis atau Pintar?

Apa yang Membuat Agent Terlihat Pintar?

Agent terlihat pintar kalau ia bisa memilih aksi berdasarkan masukan atau kondisi.

Masukan
→
Keputusan
→
Aksi Agent
→
Umpan Balik

Ingat: Agent tidak menebak sendiri. Agent mengikuti aturan yang kamu buat.

Contoh masukan: “makanan”, “aman”, atau “alat”. Contoh aksi: Agent menuju farm, membuat dinding, atau menuju tambang.
Hari 1
Diskusi Kelas

Otomatis vs Aturan Pintar

Otomatis

Agent melakukan aksi yang sama setiap kali.

Perintah: jalan Agent maju 5 langkah. Diulang lagi? Tetap maju 5 langkah.

Aturan Pintar

Agent melakukan aksi berbeda sesuai kebutuhan.

Butuh makanan → ke kebun Butuh aman → buat dinding Butuh alat → ke tambang

Pertanyaan Diskusi

Kalau semua perintah menghasilkan aksi yang sama, apakah itu sudah pintar? Kenapa?

Jawaban yang diharapkan: belum terlalu pintar, karena Agent belum memilih aksi berdasarkan kebutuhan.

Hari 2
Pohon Keputusan

Rencanakan Sebelum Coding

Hari ini kamu mengubah AI System Map menjadi pohon keputusan.

Aturan bagus dulu, kode bagus kemudian.

Kalau alurnya jelas, Agent lebih mudah dibuat dan diuji.

Pohon keputusan membantu kamu melihat pilihan player dan aksi Agent sebelum mulai membuat kode.
Hari 2
Konsep

Apa Itu Pohon Keputusan?

  • Pohon keputusan adalah peta pilihan.
  • Dimulai dari satu pertanyaan utama.
  • Setiap jawaban punya aksi berbeda.
  • Agent mengikuti cabang yang kamu buat.
MULAI Apa kebutuhan player? ├─ Makanan → ke kebun ├─ Aman → bangun dinding ├─ Alat → ke tambang └─ Tidak jelas → beri instruksi ulang
Cabang “tidak jelas” disebut fallback. Ini membantu jika player bingung atau salah mengetik.

Hari 2
Cek Teman

Apakah Temanmu Paham?

Teman mengecek:

  • Titik mulai jelas.
  • Ada 3 cabang.
  • Setiap cabang punya aksi berbeda.
  • Ada aturan cadangan.

Perbaiki jika:

  • Cabang terlalu umum.
  • Aksi terlalu sulit dibuat.
  • Jalur membingungkan.
  • Aksi Agent belum mungkin dibuat.
Kalau temanmu bingung tanpa kamu jelaskan, tambahkan sign atau perjelas aturan.

Hari 3
Debugging

Uji Satu Aturan Setiap Kali

Daftar Uji

  • Perintah makanan bekerja.
  • Perintah aman bekerja.
  • Perintah alat bekerja.
  • Agent mulai di posisi benar.
  • Player mendapat pesan.

Perbaikan Umum

  • Agent salah arah → cek belokan.
  • Agent tersangkut → kosongkan jalur.
  • Perintah tidak jalan → cek ejaan.
  • Terlalu sulit → pendekkan jalur.
Error bukan gagal. Error membantu kamu tahu bagian yang perlu diperbaiki.
Hari 3
Tantangan

Bagaimana Jika Player Bingung?

Buat perintah bantuan agar player tahu pilihan yang tersedia.

ketika pemain mengetik “bantuan” pemain berkata “Pilih: makanan, aman, atau alat.” pemain berkata “Agent mengikuti aturan yang jelas.”

Ini adalah versi mudah dari fallback rule.

Perintah bantuan membuat project kamu lebih mudah dimainkan teman lain.

Hari 4
Rekomendasi

Buat Agent Memberi Saran

Hari ini Agent tidak hanya bergerak, tetapi juga memberi rekomendasi yang masuk akal.

Rekomendasi berguna jika aturannya jelas.
Aturan kurang tepat → saran bisa salah.

Pikirkan aplikasi yang memberi rekomendasi: maps, video, game tips, atau playlist.

Rekomendasi tidak selalu benar. Karena itu manusia tetap perlu mengecek.
Hari 4
Konsep

Apa Itu Rekomendasi?

Rekomendasi

Saran yang membantu player memilih langkah berikutnya.

Perlu Dicek

Rekomendasi bisa salah jika aturan, input, atau posisi Agent bermasalah.

Kondisi PlayerRekomendasi Agent
Makanan sedikitPergi ke kebun dulu
Belum punya tempat amanBangun dinding aman
Belum punya alatKumpulkan kayu atau batu
Agent memberi saran karena kamu membuat aturan untuknya.

Tantangan

Naik Level: Variabel + Jika/Maka

Untuk kamu yang sudah cepat, coba gabungkan rekomendasi ke satu sistem.

buat variabel: kebutuhan atur kebutuhan = “makanan” jika kebutuhan = “makanan”: katakan “Pergi ke kebun dulu.” jika tidak, jika kebutuhan = “aman”: katakan “Bangun tempat aman dulu.” jika tidak, jika kebutuhan = “alat”: katakan “Kumpulkan alat dulu.” jika tidak: katakan “Pilih kebutuhan yang jelas.”
Ini opsional. Output minimal tetap boleh memakai command terpisah.
Hari 4
Literasi Digital

Apakah Agent Bisa Salah?

Bisa, jika...

  • Aturan belum lengkap.
  • Masukan player tidak jelas.
  • Jalur terhalang.
  • Agent mulai dari posisi salah.

Cek Manusia

Player harus mengecek apakah rekomendasi Agent benar, berguna, dan aman.

AI membantu. Manusia memutuskan.

Ini adalah bagian responsible AI: smart system tetap perlu diawasi manusia.
