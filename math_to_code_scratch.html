Misi 2 — Menghitung jawaban benar

Setelah dua angka muncul, game perlu tahu jawaban yang benar. Di sinilah variabel Answer dipakai.

Blok inti

when I receive [Soal Baru] set [Answer v] to ((costume name of Number 1) + (costume name of Number 2))

Bisa dijelaskan ke siswa: komputer juga perlu “menyimpan hasil hitung” supaya nanti bisa membandingkan mana jawaban yang benar.

Misi 3 — Menampilkan pilihan jawaban

Game kita butuh 3 kotak jawaban. Salah satunya harus berisi jawaban yang benar (nilai Answer).

Pilihan A

Kita atur nilainya persis sama dengan nilai Answer (Jawaban benar).

Pilihan B

Kita buat jadi jawaban salah (misalnya Answer + 1).

Pilihan C

Kita buat jadi jawaban salah lain (misalnya Answer - 1).

Misi 4
If Then
Slide 8

Misi 4 — Saat jawaban diklik

Apa yang terjadi kalau pemain mengklik jawaban yang benar? Apa yang terjadi kalau salah?

Jika jawaban benar

Kita tambah skornya, dan minta game mengeluarkan soal baru.

if <(nilai) = (Answer)> then change [Score v] by 1 broadcast [Soal Baru] end

Jika jawaban salah

Skor tidak bertambah, bisa ditambah efek suara 'error' atau teks "Coba lagi!".

if <not <(nilai) = (Answer)>> then say [Coba lagi!] for (1) seconds end
