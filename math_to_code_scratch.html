Kenapa pakai starter project?

Karena trial class harus terasa seru dan berhasil. Jadi beberapa bagian sudah disiapkan, lalu siswa melengkapi bagian inti yang benar-benar menunjukkan logika coding.

Sudah disiapkan

Backdrop, posisi sprite, tampilan skor, tampilan timer, dan struktur awal game. Jadi siswa bisa langsung masuk ke bagian yang paling penting.

✓ Stage dan backdrop ✓ Sprite angka dan operator ✓ Variabel Score, Timer, Answer ✓ Tombol mulai dan alur dasar game

Dikerjakan siswa

Siswa tetap membuat bagian coding yang bermakna, seperti mengacak angka, menghitung hasil, dan menentukan apa yang terjadi saat jawaban diklik.

✓ Random angka ✓ Set Answer ✓ Isi pilihan jawaban ✓ Klik benar = skor bertambah

Alur game yang akan kita buat

Lihat alurnya dulu, supaya siswa paham kenapa setiap blok itu dibutuhkan.

A

Game dimulai

Score di-reset, timer berjalan, lalu game mengirim pesan untuk membuat soal baru.

B

Soal muncul

Angka pertama dan kedua diacak. Operator ditampilkan, lalu hasilnya disimpan di variabel Answer.

C

Pemain memilih

Kalau klik jawaban benar, skor bertambah. Setelah itu muncul soal baru sampai timer habis.

“Coding itu menyusun langkah. Kalau langkahnya rapi, game-nya juga akan bekerja dengan rapi.”

Misi 1 — Membuat soal acak

Siswa menambahkan blok agar Number 1 dan Number 2 berubah menjadi angka acak setiap kali menerima pesan Soal Baru.

Contoh logika

when I receive [Soal Baru] switch costume to (pick random 1 to 10)

Blok ini bisa dipakai untuk sprite Number 1 dan Number 2.

Checkpoint

Saat tombol green flag ditekan dan game berjalan, angka di layar harus berubah-ubah setiap soal baru muncul.

Angka 1 berubah Angka 2 berubah Masih pakai +

Misi 2 — Menghitung jawaban benar

Setelah dua angka muncul, game perlu tahu jawaban yang benar. Di sinilah variabel Answer dipakai.

Blok inti

when I receive [Soal Baru] set [Answer v] to ((costume name of Number 1) + (costume name of Number 2))

Bisa dijelaskan ke siswa: komputer juga perlu “menyimpan hasil hitung” supaya nanti bisa membandingkan mana jawaban yang benar.

Pilih Jawaban
Slide 7

Misi 3 — Menampilkan pilihan jawaban

Untuk trial class, tiga jawaban dibuat dengan tiga sprite tetap: Choice A, Choice B, dan Choice C. Cara ini lebih ringan daripada clone.

A

Choice A

Salah satu pilihan diisi dengan nilai Answer.

B

Choice B

Diisi angka pengecoh, misalnya Answer + 1.

C

Choice C

Diisi angka pengecoh lain, misalnya Answer - 1.

Tips fasilitasi

Kalau waktunya mepet, jawaban benar tidak perlu diacak posisinya dulu. Yang penting siswa paham bahwa salah satu pilihan memakai nilai dari variabel Answer.

Misi 4
Skor
Slide 8

Misi 4 — Saat jawaban diklik

Ini momen penting: siswa melihat bahwa klik pada sprite bisa memicu aturan tertentu. Kalau jawabannya benar, skor bertambah dan game lanjut ke soal berikutnya.

Jawaban benar

when this sprite clicked if <(nilai pilihan) = (Answer)> then change [Score v] by (1) broadcast [Soal Baru] end

Jawaban salah

when this sprite clicked if <(nilai pilihan) ≠ (Answer)> then say [Coba lagi!] for (1) seconds end
