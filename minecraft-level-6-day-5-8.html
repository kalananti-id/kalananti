Hari 5
Agent + Redstone Trigger

Player Bisa Memberi Input Fisik

Sebelumnya player mengetik command. Hari ini player juga bisa menekan tombol, menarik lever, atau menginjak pressure plate.

Player Action
→
Redstone Signal
→
World Feedback
→
Agent Mission

Contoh: tekan tombol Food → lampu menyala → ketik makanan → Agent menuju kebun.

Redstone tidak harus langsung menjalankan Agent. Untuk hari ini, Redstone menjadi tanda bahwa misi dipilih.
Hari 5
Konsep Redstone

Input dan Output di Minecraft

Input

  • Button
  • Lever
  • Pressure Plate
  • Player berdiri / menekan sesuatu

Output / Feedback

  • Redstone Lamp menyala
  • Door terbuka
  • Piston bergerak
  • Trapdoor terbuka

Game yang baik memberi feedback. Kalau player menekan sesuatu tapi tidak ada tanda, player bisa bingung.

Feedback harus terlihat jelas. Gunakan lampu atau pintu jika masih belajar.

Buat Trigger Station

Buat satu stasiun dengan 3 pilihan misi.

Food Button

Button → Redstone Dust → Lampu

Setelah menyala, ketik: makanan

Safety Lever

Lever → Redstone Dust → Door/Lampu

Setelah aktif, ketik: aman

Tool Pressure Plate

Pressure Plate → Redstone Dust → Lampu

Setelah aktif, ketik: alat

Sign utama: TRIGGER STATION Tekan trigger, lihat feedback, lalu panggil Agent dengan command.
Beri jarak antar trigger agar kabel Redstone tidak saling menyambung.

Hari 5
Safety Mission

Trigger 2: Safety Lever

Kenapa Lever?

Lever cocok untuk sistem yang punya keadaan aktif dan nonaktif.

Feedback

Boleh pakai lampu menyala atau pintu terbuka sebagai tanda misi Safety aktif.

Sign: SAFETY MISSION Tarik lever. Jika pintu/lampu aktif, ketik: aman
Untuk versi mudah, pakai lampu. Untuk versi lebih seru, pakai iron door.

Pressure Plate

Pressure plate aktif saat player berdiri di atasnya. Ini seperti sensor sederhana.

Alur

  • Injak pressure plate.
  • Lampu menyala.

Sign: TOOL MISSION Injak pressure plate. Jika lampu menyala, ketik: alat

Hari 6
Konsep

Command Block Itu Apa?

Command Block

Block khusus yang menjalankan command di world Minecraft.

Fungsinya

  • Memberi pesan misi.
  • Memberi item.
  • Memberi efek.
  • Teleport player.
Untuk mendapatkan command block: /give @p command_block
Gunakan command block untuk membantu gameplay, bukan hanya untuk membuat efek yang tidak nyambung.
Hari 6
Command Utama

Gunakan Title untuk Memulai Misi

Title memberi tanda besar di layar, jadi player tahu misi sudah aktif.

Food

title @p title Food Mission Started

Safety

title @p title Safety Mission Started

Tool

title @p title Tool Mission Started

Setelah title muncul, player menjalankan command Agent: makanan, aman, atau alat.

Di Command Block, biasanya tulis command tanpa slash di depan. Kalau tidak jalan, coba cek mode dan trigger-nya.

Failure Case

Apa yang Bisa Gagal?

NPC

Instruksi tidak jelas, player tidak tahu mulai dari mana.

Trigger

Button ditekan, tapi tidak ada feedback.

Command Block

Title tidak muncul atau command salah.

Agent

Agent salah arah, tersangkut, atau tidak sesuai rules.

Feedback

Player tidak tahu apakah sistem bekerja.

Human Check

Player lupa mengecek hasil Agent.

Failure case adalah kondisi saat sistem tidak berjalan seperti yang diharapkan.
