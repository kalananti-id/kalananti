Langkah 1
Papan Soal
Slide 4

Membuat tembok soal

Pada part Soal, tambahkan SurfaceGui lalu isi TextLabel. Ini yang akan menampilkan pertanyaan matematika.

1

Siapkan part soal

Buat part besar di depan jalur. Ubah namanya menjadi Soal. Pastikan Anchored = true supaya tidak jatuh.

PartAnchoredName = Soal
2

Tambahkan tulisan

Klik kanan part Soal → Insert Object → SurfaceGui → tambahkan TextLabel.

Atur TextLabel: TextScaled = true BackgroundTransparency = 1 TextColor3 = warna gelap Font = sesuai kebutuhan

Script contoh untuk papan soal

Script di dalam TextLabel pada Soal
local TextSign = script.Parent local Part = script.Parent.Parent.Parent TextSign.Text = "Rata-rata dari 6 dan 10 adalah..."
Langkah 2
Jawaban Benar
Slide 5

Membuat tembok jawaban benar

Pada tembok jawaban benar, teks harus benar dan part harus bisa ditembus supaya pemain bisa lewat.

Rata-rata dari 6 dan 10 adalah...
7
8

Yang harus diubah

Name = BenarJawaban = 8CanCollide = false
Script di dalam TextLabel pada Benar
local TextSign = script.Parent local Part = script.Parent.Parent.Parent TextSign.Text = "8" Part.CanCollide = false

Karena CanCollide = false, karakter bisa menembus tembok ini. Ini menandakan pemain memilih jawaban yang benar.

Langkah 3
Jawaban Salah
Slide 6

Membuat tembok jawaban salah

Pada tembok jawaban salah, part tetap padat dan diberi script sentuh. Saat pemain menyentuhnya, karakter langsung mati lalu respawn.

Script teks jawaban salah

Script di dalam TextLabel pada Salah
local TextSign = script.Parent local Part = script.Parent.Parent.Parent TextSign.Text = "7"

Untuk jawaban salah, tidak perlu mengubah CanCollide. Biarkan part tetap padat.

Script mematikan pemain

Script di dalam part Salah
local DamagePart = script.Parent local function Touch(otherPart) local character = otherPart.Parent local humanoid = character and character:FindFirstChild("Humanoid") if humanoid then humanoid.Health = 0 end end DamagePart.Touched:Connect(Touch)
Urutan Kerja
Step by Step
Slide 7

Urutan membuat obby quiz

Ikuti urutan ini supaya hasilnya rapi dan tidak bingung saat mengetik script.

1

Buat jalur dan SpawnLocation

Siapkan tempat mulai, jalur lurus, dan ruang untuk memasang dua tembok jawaban.

2

Buat part Soal, Benar, Salah

Ubah nama object dengan jelas supaya script mudah dipasang dan dicari.

3

Tambahkan SurfaceGui + TextLabel

Pada ketiga part, buat tulisan yang menghadap ke arah pemain.

4

Isi teks pertanyaan

Ketikan soal pada part Soal dan isi pilihan jawaban pada part Benar dan Salah.

5

Buat Benar bisa ditembus

Pada script Benar, atur Part.CanCollide = false.

6

Buat Salah mematikan

Pada part Salah, pasang script Touched agar pemain mati saat memilih jawaban salah.
