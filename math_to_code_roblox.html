Slide 3

Ayo Susun Blueprint-mu! 🏗️

Sebagai Game Developer, kamu harus rapi. Yuk, buat struktur folder di Explorer kamu seperti ini supaya script-nya tidak tertukar!

Susunan di Explorer

Coba buat 3 Part, lalu ganti namanya (Rename) menjadi seperti ini:

Workspace ├─ 🚩 SpawnLocation (Tempat mulai) ├─ 🧱 Soal (Tembok besar) │ └─ SurfaceGui ➔ TextLabel ├─ 🟩 Benar (Jalur tembus) │ └─ SurfaceGui ➔ TextLabel ├─ 🟥 Salah (Jalur jebakan) │ └─ SurfaceGui ➔ TextLabel └─ 🔥 Rintangan (Lava - Rintangan Tambahan)

Tugas Setiap Part

Soal: Papan pengumuman pertanyaanmu. Benar: Pintu ajaib yang bisa ditembus. Salah: Jebakan yang bikin pemain respawn. Rintangan: Rintangan tambahan yang membuat game lebih menantang.

💡 Pro-Tips Game Dev:

  • Rename adalah kunci: Jangan biarkan namanya cuma "Part", nanti kamu bingung saat coding!
  • Anchor: Jangan lupa di-Anchor semua ya, supaya map kamu tidak "jatuh" saat game dimulai.

Membuat Tembok Soal

Tembok soal adalah petunjuk utama bagi pemain. Yuk, ubah Part biasa jadi layar digital yang menampilkan tantangan matematika!

1

Bangun Fondasi Tembok

Munculkan Part, buat jadi lebar seperti tembok, dan Rename menjadi Soal.

Wajib: Anchored = ON ✅


Tips: Atur warna tembok agar kontras dengan warna tulisan nanti.

2

Pasang Layar Digital

Klik tanda (+) pada part Soal, lalu tambahkan komponen ini secara berurutan:

              1. SurfaceGui (Sebagai Layar)

              2. TextLabel (Sebagai Tulisan)

⚙️ Pengaturan Wajib:
  • Cari Size, ubah jadi: 1, 0, 1, 0 (Supaya tulisan memenuhi seluruh papan!)
  • Centang TextScaled agar otomatis besar.

📜 Script: Mengisi Pertanyaan

Masukkan Script ke dalam TextLabel kamu, lalu ketik kode "ajaib" ini:

Script Papan Soal
            local TextSign = script.Parent

            -- Ganti teks di bawah ini sesuai soal yang kamu mau!
            TextSign.Text = "Rata-rata dari 6 dan 10 adalah..."
Ubah teks di dalam tanda kutip " " sesuai kreativitasmu!

Membuat Tembok Benar ✅

Tembok ini akan menipu mata pemain! Kelihatannya padat, tapi karena jawabannya benar, pemain bisa menembusnya seperti hantu.

Script Teks Jawaban Benar

CanCollide = false

Script di dalam TextLabel (Benar)
          local textSign = script.Parent
          local Part = script.Parent.Parent.Parent

          -- Masukkan jawaban yang benar
          textSign.Text = "8"

          -- Kode ajaib untuk membuat tembok bisa ditembus!
          Part.CanCollide = false
Logika Game:
Saat CanCollide bernilai false, benda tersebut tidak lagi memiliki tabrakan fisik. Itulah kenapa kita bisa melewatinya!

Tembok Jawaban Salah
Slide 6

Bikin Tembok Salah 💀

Hati-hati! Berbeda dengan tembok jawaban benar, tembok ini tetap padat. Jika pemain menyentuhnya, script kita akan membuat karakter mereka kalah dan harus mengulang.

Script Teks Jawaban Salah

Script di dalam TextLabel (Salah)
              local TextSign = script.Parent
              local Part = script.Parent.Parent.Parent

              TextSign.Text = "7"

Untuk jawaban salah, tidak perlu mengubah CanCollide. Biarkan part tetap padat.

Script Mematikan Pemain

Script di dalam part Salah
              local DamagePart = script.Parent

              local function Touch(otherPart)
                local character = otherPart.Parent
                local humanoid = character and     character:FindFirstChild("Humanoid")

                       if humanoid then
                           humanoid.Health = 0
                     end
                end

              DamagePart.Touched:Connect(Touch)

Rencana Kerja Game Dev 🛠️

Ikuti urutan ini supaya kuis kamu berjalan sempurna. Jangan sampai ada langkah yang terlewati!

1

Persiapkan Arena

Pasang SpawnLocation dan buat jalur lurus untuk area kuis kamu.

2

Susun Blueprint

Buat 3 Part, Rename (Soal, Benar, Salah), dan wajib nyalakan Anchor.

3

Pasang Layar

Tambahkan SurfaceGui dan TextLabel di setiap tembok jawaban.

4

Tulis Pertanyaan

Gunakan script untuk mengisi teks soal dan pilihan jawabanmu.

5

Pintu Ajaib

Pasang script CanCollide = false hanya di tembok jawaban yang benar.

6

Pasang Jebakan

Gunakan event Touched di tembok salah agar pemain respawn.

🚀 Tips: Setelah langkah 6 selesai, langsung klik tombol Play untuk mencoba kuis buatanmu!
